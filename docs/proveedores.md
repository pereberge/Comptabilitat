# Cambio de alcance

El módulo independiente de proveedores se ha retirado a petición del usuario. La gestión se centraliza en Mantenimiento de subcuentas, con un formulario único y tipo deducido por el backend.

La migración 003 y los datos ya existentes se conservan. No se expone la API de proveedores. Las futuras fichas de terceros se vincularán a las cuentas según su numeración; todavía no están implementadas.
